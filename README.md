# 鳥類カウント Ver. 1.4

## ファイルの役割
- `index.html`：画面の項目・並び順
- `css/style.css`：配色・余白・種名ボタンの列数（`.grid` の `repeat(3,...)`）
- `js/app.js`：種名ボタン・記録入力・編集・範囲集計・CSV・GPS
- `js/storage.js`：手動JSONバックアップ・復元
- `sw.js`：PWAオフライン用キャッシュ（公開更新時はキャッシュ名も更新）
- `manifest.webmanifest`：ホーム画面の名前とアイコン

## 編集のしかた
1. VS Codeでフォルダを開きます。
2. 色や列数を変えるときは `css/style.css` の末尾のスタイルを確認してください。
3. `index.html` をローカルで開けば基本画面を確認できます。GPS・PWAの動作確認にはHTTPS環境が必要です。
4. GitHub Pagesではこのフォルダの中身を公開対象のリポジトリに置き、コミット・pushすると更新できます。
5. オフラインキャッシュの更新時は `sw.js` の `CACHE` 名を新しい版へ変更します。

## データとバックアップ
- 記録はブラウザ内のlocalStorageに保存されます。GitHubに観察記録が自動送信されることはありません。
- CSV：記録一覧から全件出力。ExcelやRでの解析向け。
- JSON：設定画面から手動保存・復元。復元時は既存記録を**置換**します。
- JSON保存日時はダウンロードを開始した時刻です。ファイルが実際に保存されたか必ず確認してください。
- 異なる端末・ブラウザ・URLでは保存領域が別です。初回公開前に旧版のCSVを保存してください。
- Wi-Fi接続時の自動バックアップはありません。
- GitHub Pagesへの公開にはGitHubリポジトリのPages設定が必要です。


## Ver. 1.4 追加機能
- 性別・年齢を含む既存選択肢を編集できます。変更しても過去の値は書き換えません。
- 設定画面から単一選択、複数選択、数値、自由記述の項目を追加できます。
- 追加項目は記録一覧・CSV・JSONバックアップに含まれます。
- 追加項目は「非表示」にしても過去の記録を保持します。
- JSONバックアップ形式はversion 2です。旧version 1の復元にも対応します。
- 公開更新前に既存アプリでJSONバックアップを保存し、別の端末・URLではデータが共有されない点に注意してください。

## CSV共有（Ver. 1.4）
- 記録一覧の「CSVを共有する」で、対応するiPhone等の共有メニューからメールや「ファイルに保存」を選べます。
- 非対応のブラウザではCSVダウンロードに切り替わります。
- 「CSVを保存する」は従来のダウンロード機能です。
- CSVにはカスタム記録項目も含まれます。ファイル名はローカル日時付きです。
- CSV共有は送信を自動実行しません。共有先のアプリで送信操作を完了してください。
